# Email-only private draft-note candidate

This branch starts from base source `36fa8f66` (App `1.9.0-preview.5`, Runtime `0.4.0-preview.3`) and declares App `1.9.0-preview.6` / Runtime `0.4.0-preview.4`. It reuses the reviewed optional private draft-note implementation from Preview4. The note is limited to 1000 characters, survives encrypted draft restart, and never enters outgoing MIME. New note-capable drafts expose the optional control; retained pre-upgrade drafts keep their original form and do not gain the control through an on-read mutation or migration. Base polling, Compose and navigation fixes remain present. Packed Kit33 bytes and Host contracts are unchanged.

Local package/parser/restart checks demonstrate the author-owned change. They do not establish live upgrade acceptance: Root must use the ordinary stage/review/activate flow in the fresh namespace, issue current same-account authority and inspect the resulting trusted form under the same frozen Host. No historical unknown Run is replayed. The main candidate's broader Runtime suite and its disclosed baseline/platform failures remain separate evidence.
